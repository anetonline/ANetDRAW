## Built with

- **OpenDoors** door toolkit: originally by Brian Pirie, maintained at
  <https://github.com/RealDeuce/OpenDoors>. GNU LGPL 2.1; the license
  text is in `LICENSE-OpenDoors.txt`, and the OpenDoors source ANetDRAW
  is built from (with its local fixes) is in the ANetDRAW source
  repository under `third_party/OpenDoors`.
- **stb_image** and **stb_image_write** by Sean Barrett
  (<https://github.com/nothings/stb>), public domain / MIT: image import
  and PNG export.

## Fonts and art formats

- **TheDraw** and its `.TDF` font format by **Ian E. Davis** (TheSoft
  Programming Services).
- **The TheDraw font pack** was built from the collection preserved by
  **Roy/SAC** (<https://www.roysac.com/thedrawfonts-tdf.html>), drawn by
  BBS-era artists; see `fonts/FONTS.md` in the font pack for details and
  the named authors. Roy/SAC's TDF format notes, **tdfiglet**, and
  Synchronet's `tdfonts_lib.js` were the references for reading the
  fonts.
- **TheDraw's outline styles**: the table as documented by **retrofont**
  (Mike Krüger, Apache-2.0).
- **The IBM VGA 8x16 font** in the Windows window and PNG export, taken
  from **Moebius** (Andy Herbert, <https://github.com/blocktronics/moebius>).
- **SAUCE** by Olivier "Tasmaniac" Reubens of ACiD Productions, and the
  **XBin** and **BIN** art formats of the same scene.

## References

- **Synchronet** (Rob Swindell, Stephen Hurd and contributors) and
  **SyncTERM**: Ctrl-A codes, ZMODEM behavior, the DECSCS speed
  sequence, and how BBSes pass input to doors.
- **lrzsz** (Uwe Ohse, after Chuck Forsberg's rz/sz): the ZMODEM
  reference used to test ANetDRAW's transfers. Not shipped.
- **PCBoard** `@X` codes and **Renegade/Mystic** pipe codes.
- **Mystic BBS** (g00r00) documentation for door setup.

Thanks to the ANSI art scene and every sysop keeping BBSes alive.
