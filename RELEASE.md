# ANetDRAW v0.1.0 — first private beta (September 2026)

First test build of ANetDRAW, the ANSI/ASCII art editor door for BBSes (C / OpenDoors; Linux, Raspberry Pi and Windows). Drawing tools with mouse support, TheDraw fonts, save/open with SAUCE and TheDraw-style save options, ZMODEM downloads, a shared gallery, and a native Windows window for local mode.
